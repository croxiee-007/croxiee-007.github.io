# Tirupati Pilgrimage — 5–7 October 2026

Static single-page website for the Hyderabad → Kanchipuram → Tiruttani → Tirumala → Tiruchanur → Hyderabad pilgrimage.

## Publish as HTTPS

### GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and this README.
3. In **Settings → Pages**, select the `main` branch and `/root`.
4. GitHub will provide the HTTPS page URL.

### Netlify / Cloudflare Pages
Upload the folder as a static site. No build command is required.

## Images
The page uses verified Wikimedia Commons image URLs. If a local/offline preview blocks external images, each photo automatically falls back to an embedded temple illustration instead of showing a broken-image icon. When served online, the Wikimedia photos are used when available.
